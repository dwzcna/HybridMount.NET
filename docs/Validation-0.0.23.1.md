# 0.0.23.1 验收记录

## 实现和边界

首页移除旧管理工具栏和空行；设置、日志、管理卡片按内容宽640 DIP单／双列，概览通栏，只有页面统一滚动。管理和全部任务入口使用23.0独立按钮；全部任务经TaskFocus清除挂载、路径、问题、冲突及任务定位。

Commons只读生命周期契约、Models不可变快照、应用级TaskOverviewService和HomeViewModel分开。业务成功提交后同步交付轻量内存统计，当前模式全部挂载及应用任务按业务行计数，不以任务页最近100条历史为计数源。轮次、重试、四类结果、迟到尝试、初始化竞态、读失败补读及退出拒绝迟到分别保护。首页250ms合并发布，离页／托盘隐藏不发布，统计继续；查看首页不发远端请求、不控制任务。

源投影复用原提交连接；当前SaveOperation对象不重复解析结果JSON。活跃远端父批次首次装载后按受影响成员增减，纯下载父项仍缓存分类，避免每个独立下载重扫整批。读取失败保留遗漏ID，后续提交补齐再清除错误。初读失败保持提示，后续提交唤醒单后台补读。所有缓存仅进程内，不新增数据库、备份、公共IPC字段。

用户补充的历史尝试右侧留白在本版提交前修正：UserControl、ScrollViewer及Expander本体拉伸，长标题换行；保持内距、折叠箭头及纵向滚动，不设置固定正文宽度。
