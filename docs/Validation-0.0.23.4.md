# 0.0.23.4 验收记录

## 判断与实现

基线为0c49aca（23.3）。用户反馈约一秒的恢复等待未在生产机重新测量；没有加入或发现固定一秒等待。本版处理已证实的状态耦合、全挂载刷新、UI读业务锁和重复能力渲染，不声称它们是生产端全部耗时的唯一来源。

挂载页命令保持内部串行接纳并持有整条Task；打开模态不改变CanExecute，重复入口直接拒绝。导入从文件选择到预览及新建转交共用占用，取消省略Refresh／NotifyStateChanged。三协议共用纯ProtocolInteractionState与交互ViewModel，普通按钮走RelayCommand；真实操作状态驱动原生主次按钮及输入组。选择目录只执行视图选择回调并写回路径，不刷新能力或验证目录；最终提交的路径、空目录、身份、草稿代次和认证保护保留。

只读测试锁定服务器／凭据等依赖输入；独立文本草稿保持可编辑，即时写配置的开关／保存继续互斥。提交冻结完整草稿。测试、SQS、能力及关闭的取消入口保持；旧任务只清除自己的活动记录，不释放其他原因。RelayCommand的模态流程由模型保存完整Task，未全局开启AsyncRelayCommand并发，也未用无人持有的fire-and-forget缩短执行周期。

备份等待保存位置不再禁用表单，真实读取／解密／接纳才进入业务状态；原有错误、取消和原子备份逻辑保持。日志等待选择／确认不禁用底层，实际导出跨读取和写文件的完整周期与清除互斥，阅读及筛选继续。设置确认仅持内部占用，确认后才冻结业务，并再次等待预检期间可能启动的设置写入。遗留目录选择也仅在实际身份检查阶段限制冲突选择。

挂载行按派生值差异通知，纯可用性不排版；内存故障投影代替UI连接锁查询，重连业务入口仍在服务中重验当前根。能力按草稿代次、配置／凭据修订和证据引用复用，语言观察仍独立更新。受影响XAML的41个命令绑定无Click双执行或重复IsEnabled来源；command-bindings-audit.json。

明确例外：原生ContentDialog的主次提交／取消、Closing／Closed／deferral；Toggle、规则删除的行身份、挂载卡片／菜单捕获ID及系统链接继续用薄的原生事件适配，不做机械命令替换。主次可用性和普通输入仍由ViewModel提供；不改变原生遮罩、窗口所属和系统焦点，不强制启用HWND。

schema8、注册表根、hmxbk、公共IPC及包身份不变。Ext／Stock源码和工程对52cda0f零差异，NativeShared不存在；编译版本统一23.4。

## 恢复时序与版本对照

restoration-timings.json从实际窗口的Stopwatch分段记录生成。每种规模每配置：导入取消100样本，三协议目录选择合计300样本。区分注入选择回调释放→回调返回→完整流程Task收尾→下一次CompositionTarget.Rendering机会。

| 配置／规模 | 导入P95／最大(ms) | 目录选择P95／最大(ms) |
|---|---:|---:|
| Debug／0 | 31.969／34.416 | 34.218／52.851 |
| Debug／1 | 31.833／33.545 | 34.935／52.938 |
| Debug／100 | 31.516／31.854 | 35.210／70.887 |
| Release／0 | 31.827／32.408 | 34.234／46.980 |
| Release／1 | 31.703／33.131 | 34.835／47.920 |
| Release／100 | 31.592／31.886 | 34.088／66.135 |

这些应用阶段样本满足P95≤100／单次≤250ms，取消不产生挂载Refreshed、挂载行或命令可用性通知；路径结果、证据代次和关闭保护另作断言。Rendering是下一次UI绘制机会，尚未通过像素或真实输入确认系统首个可交互画面；系统选择器关闭到回调的时间未测，不能将表格宣称为生产端到端时延。

受控对照使用真实23.3二进制和最终23.4，各自0／100项窗口：modal-baseline-count*.json与final-modal-current-count*.json。100项一次模态往返，23.3四按钮额外禁用，挂载行通知200次、Refreshed一次；23.4原启用外观保持、两项计数均0。持有一个ConnectionSync约500ms后释放模态，23.3收尾512.522ms，23.4为0.0322ms；无锁分别5.975／0.116ms。它验证被移除的UI等待链，不证明生产机已发生相同锁争用。后者只是一小段收尾测量，完整应用绘制机会数据单独列于上表。

## 过程异常与未执行范围

初次最小编译修正缺少MountActionState命名空间；能力回调类型适配修正Action<string>／Action<Exception>。首轮142项有两项失败：新测试用Checking状态错误假设CanEdit可变；另一项暴露重连执行入口错误依赖尚未发布的展示故障投影，已改为执行时交给服务核验真实根。修正并扩大后最终两配置241项通过；debug-first-behavior.trx等保留失败证据。

辅助UI探针曾有局部变量重名。对照探针复用同项目RAR缓存时，名为current的首次输出实际仍加载23.3；这些modal-current[-stale]-count*.json不计入当前结果。隔离缓存时又出现生成特性重复，最终采用独立ModalCurrentProbe项目、核对实际加载版本及进程结果完成正确23.4对照。失败日志和原输出保留，不混入通过计数。

Windows computer-use像素工具在本轮会话初始化与重置重试均失败（helper_unknown_error，见23.3同会话记录）；离屏RenderTargetBitmap图片不完整。没有声称像素画面或系统选择器已通过，未尝试绕过工具权限。
