## 规则

业务Button／AppBarButton／支持命令的菜单优先绑定现有Toolkit的RelayCommand／AsyncRelayCommand；CanExecute为纯内存判定，状态真实变化才精确通知，不再与代码IsEnabled或重复Can绑定竞争。原生ContentDialog认证／提交保留事件、deferral、失败留输入及接纳后才关闭；输入组与原生属性绑定交互ViewModel。ViewModel不持控件、XamlRoot或Picker，通过纯回调桥接视图，异步执行由明确所有者保存并观察。

仅打开ContentDialog或系统选择器，不额外禁用底层页面、工具栏或表单。模态占用只在首个await前防重入，重复请求直接拒绝，不补开；不全局放开并发命令，不改变原生遮罩、HWND或焦点限制。真实认证、提交、探测、读写仍按操作代次及资源冻结冲突范围，取消入口保持；一个完成只能释放自己的原因，迟到和关闭不得误解锁。

挂载页纯取消省略全挂载刷新；输入本地路径不请求网络或失效无关能力。导入选择→解密预览→新建是同一模态流程。只读测试冻结连接与凭据相关字段，新建草稿的独立字段可继续编辑；提交冻结整个参与草稿。局部设置只限制实际资源冲突。日志选择器不因模态灰页，实际导出与清除互斥但阅读筛选可继续。

可用状态由UI Dispatcher即时发布，不进入进度节流或固定延时。显示判定不等连接锁／DB／文件或CFAPI；挂载行按值通知，纯可用性不重测按钮。能力按实际证据／语言变化渲染，保留焦点、滚动、折叠和原系统动画。
