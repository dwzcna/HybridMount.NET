## 2. 任务概览与统计规则

### 展示范围

- 统计当前运行模式、全部挂载及应用级任务，以任务页“全部”中的业务任务为单位。
- 一个“应用远端更改”合并任务计一项，每个独立下载任务计一项；内部扫描、网络请求、下载分块和已合并的成员不重复计数。
- 最多显示 **3 个正在执行的任务**，沿用任务页稳定顺序，显示操作名称、所属挂载、目标及实际状态；超过三项时提示其余正在执行的数量，不自动轮播。
- 点击“查看所有任务”通过现有任务定位服务清除挂载、路径、问题和冲突筛选，进入任务页“全部”。

### 本轮边界

- 从没有未结束任务变为有任务时开始一轮，期间新增任务加入同一轮；全部成员结束后关闭该轮，保留结果，下一轮开始时重新统计。
- 同轮按任务 ID 去重。排队、容量等待、权限阻止、冲突、取消中和结果待核对均不算结束；没有正在执行的任务时，显示“等待处理”，不能提前结束整轮。
- 同轮重试复用原成员，撤回其原终态计数后更新状态；上一轮已经结束后的重试进入新一轮。迟到的旧尝试结果不得覆盖新尝试。
- 不使用时间窗口合并轮次，不因导航、隐藏到托盘或任务历史清理重新统计。

### 进度与结果

- 显示进度条及“**已结束 X／总任务数 Y**”。
- 成功、失败、部分失败、中断、取消、忽略和被新版本替代均计入已结束；分别汇总为成功、失败、取消、跳过四类，其中部分失败／中断归失败，忽略／被替代归跳过。
- 新增任务或重试可能使比例下降，按真实数量更新，不人为维持递增。
- 全部结束后显示“本轮已结束”；只有全部成功才显示全部成功，不将 100% 等同于全部成功。
- 首次没有任务时显示“暂无任务”，不显示无意义的 `0/0`。读取失败保留上次结果并提示更新失败，不能伪装为空闲。

## 3. 数据、接口与生命周期

- 新增应用级 `TaskOverviewService`，由应用启动和退出流程管理；`HomeViewModel` 负责绑定与导航，页面不拥有后台任务。
- 在 Commons 增加只读概览契约，在 Models 增加概览快照，包含轮次状态、总数、各状态数量及最多三项运行任务。
- 复用现有任务展示归并规则，在任务接纳、状态提交、重试及结束后更新统计。接入已提交的生命周期通知，快速开始并结束的任务也必须被记录。
- **不能直接按任务页列表计数**：当前终态历史有最近 100 条限制。轮次成员与计数由应用级服务独立维护，避免历史截断、清理或 UI 刷新合并造成漏计。
- 状态采集与界面刷新分离；UI 沿用现有后台快照机制，最多每 250 毫秒合并发布一次，按任务 ID 更新原行。首页不可见时停止界面发布，应用级统计继续运行。
- **轮次仅保存在本次进程内**。重启后按现有业务恢复结果中的未结束任务开始新一轮，旧终态历史不计入；不改变业务恢复行为。
- 本版不升级数据库、不扩展公共 IPC 或备份格式。新增文案进入现有三语言资源，命名使用 UI／UserInterface。
