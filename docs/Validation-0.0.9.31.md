# 0.0.9.31：卸载重装后的遗留同步根处理

日期：2026-11-07。范围为当前用户、本产品、未由可见现有配置管理的遗留根发现和离线清空注销；开发和自动验证预算6–10小时，真实卸载重装、GUI及实机等待另计。本版独立本地提交，不推送。

## 已实现

- 挂载页增加“遗留挂载”入口，合并WinRT、Shell当前SID的精确产品注册及未完成恢复日志；另可手动选择旧目录。发现只读，不扫描全卷、不补造正式挂载、不猜服务器或恢复旧凭据，不复制两种运行模式配置。可见两模式定义与当前运行对象都排除，路径重叠或同MountId被管理时拒绝。
- 原生RootMarker、Product／Schema／Owner、当前SID、NTFS、非卷根绝对路径、祖先重解析点、文件身份及CF_SYNC_ROOT_BASIC_INFO.SyncRootFileId共同证明所选目录就是根本身；根内子目录不能冒充根。删除前重新核验，发现快照不能替代当前身份。
- 用户选择并二次明确确认后，独立无文件源的离线CFAPI连接复用现有删除确认及MountContentCleaner。仅属性权限、句柄删除，不水合、不初始化上传、不发远端请求；普通链接仅删除链接本身。清空后保留原空目录，根文件身份保持。
- 恢复JSON与精确注册树备份在当前数据目录Recovery内原子保存，记录Confirmed／Clearing／Unregistering／NativeRemoved／Completed。每次启动只展示未完成工作，不自动重放删除。部分失败、占用和取消保留已完成结果，需再次显式确认；原生注销后只接受同身份空根，出现新本地内容即停止，不用旧日志继续删除。
- 优先WinRT注销；卸载旧包造成不可见或0x80070490时，确认同一空根后使用受支持CfUnregisterSyncRoot。原生注销完成后仅收尾有备份且原始快照、当前SID所有者、唯一UserSyncRoots路径一致的精确Shell键；每根随机NameSpace／CLSID还需核对精确ID、目标路径和无其他根引用。不更改共享系统类、文件关联、ACL或其他用户项。注册变化或权限不足单独报告，保留现场；不自动提权、不重建正式根、不重启Explorer。
- 注销和注册收尾期间持有祖先及空根属性租约，阻止路径移动或链接替换。应用OwnAsync、配置门锁和同步停止检查共同防重复、与新建／导入竞争及退出后的迟到删除；取消传播窗口不允许继续下一项。页面负责对话框与选择器，列表、选择和命令归MountsViewModel；离页不停止应用任务，真正释放取消等待并隐藏对话框。
