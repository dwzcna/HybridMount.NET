# 0.0.18.0 验证记录

## 范围与实施

当前工作基于 `4807a4e`（0.0.17.1）。新包身份 `dwzcn.HybridMount.NET`，产品、注册表、物理缓存前缀统一 HybridMount.NET；打包和非打包模式保持隔离。不迁移旧包、旧目录、配置或挂载；`.hmxbk` 编码及凭据加密保持。旧源码身份文本仅改为历史描述，不改 Git 历史和机器数据。

包内原生进程挂起创建，显式桌面包策略和标准流继承白名单，加入 Job 后核验实际完整包身份、映像、SID、会话，再恢复并沿用原有版本／nonce／进程认证。原生运行时也比较完整包全名；解码、观察子进程及 Ext 的回退启动保持包环境。诊断保留创建阶段和父子身份，不放宽握手。

设置新增当前模式全部挂载的只读确认和逐根移除，包含离线及连接失败根。保留已缓存文件只解除完整占位、保留普通文件和链接本体，只有干净且无保护的不完整占位可删除。先排空源，使用无源禁止水合的会话，原生独占保护句柄再次核对身份／内容戳／完整性。未决上传回执、快照或改名在固定移除意图前拒绝，允许重新连接核对；内容处理开始后按原模式和逐根持久日志恢复，不自动重放。不同模式任务跳过，同模式活动任务复用。新建、导入、重置及重复批次有门禁；失败继续下一根，任务页可取消或显式继续。注册和真实 Explorer 入口核验通过后才删除配置和凭据。

## 实际证据

证据目录 `artifacts/validation/00180-work/`。

- 原生启动首轮定向 Debug 30/30，通过无根实际启动、私有传输和四类身份不一致拒绝。
- 缓存／批次首轮运行 12 项中 9 项通过；两项误把无需改写的普通文件占用视为失败，一项测试联接清理失败。改为完整占位锁冲突和真实逐根检查点失败，增加链接本体清理后 12/12 通过。
- 扩展首轮 Debug 80 项中 76 项通过。发现未知注册有物化索引的移除准备缺少重验，已补保护；其余为旧夹具在非空目录重新注册、过度限定异常类型，以及250ms合并通知后的取消检查点不确定。改为安全注销边界、精确拒绝代码和仅测试逐项检查点，等待复验。
- 后续83项回归81项通过：两项夹具分别违反已有保护MAX写入规则和已固定移除模式。改为完整本地恢复和原清空模式继续，全部通过。新增任务链接回归补齐历史记录后，最终Debug／Release各100/100、0失败／0跳过，分别见`debug-final4.trx`和`release-final.trx`。涵盖离线保留、完整／不完整／普通／链接、原生拒绝过期戳／错误身份／完整文件删除、保护项与恢复、未知回执、锁冲突、逐项取消／重启、批次门禁／顺序／部分失败／模式冲突，以及原传输和任务视图。
- 主矩阵后将完整缓存用例强化为实际Pinned文件，Debug／Release追加各1/1通过，见`pinned-debug.trx`和`pinned-release.trx`；产品逻辑未改变。
- 最小及末次x64 Debug非打包编译、最终x64 Release非打包编译通过。三语言1236键、原生8项三语言校验通过。
- 失败测试留下三个精确GUID目录：两个保护项夹具及一个已移除但带只读联接的夹具。独立辅助程序仅匹配本轮目录、测试名称、配置／日志／原生根身份，沿原缓存模式完成；核验无同步根、无云占位后删除测试目录和自有测试注册。证据`cleanup-probe.log`，当前该测试目录无残留，不涉及正式挂载。
- 随机独立 MSIX 使用生产编译的 Stock；首轮包名超过清单50字符限制，未安装；第二轮探针名不满足生产的父映像名规则，包身份一致但按预期拒绝。更正独立探针文件名为 HybridMount.exe 后，实际包身份、映像、SID、会话及三管道握手通过，错误映像拒绝、停止排空通过。证据 `launch-probe-third.log`、`launch-probe-result.json` 和 `launch-probe-package.json`。随机探针包已经卸载，未注册CFAPI、菜单或缩略图处理器。
