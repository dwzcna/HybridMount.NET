## 过程失败与修正

1. 新 helper 的 Opening 事件 sender 可空性不匹配导致 CS8622，并触发 XAML pass2 级联错误；修为 object? 后增量编译通过，未清缓存。
2. 初次仅缩主区时原生两条 Auto 行使文字偏上；真实渲染后将图文所在第一行设为星号行并垂直居中。
3. 附加筛选检查发现迟到模板样式会把主区撑回 42 DIP；原始证据保留在 `height-ui-debug-aux-attempt1.json`、`height-ui-debug-aux-attempt2.json`。修正折叠图标留白和实际 SizeChanged 有界校准后，最终两配置各 188 组通过。探针在异常高度时延后 500ms 保存诊断，最终未触发该路径。

4. 提交前差异检查发现任务页外层行号调整误及卡片内部 ID／进度行；已恢复为第 2／3 行。追加标准／紧凑×600／1900 宽度四组实际生成任务卡片，验证 ID 下边缘小于进度条上边缘，最终两配置各 188 组通过。
