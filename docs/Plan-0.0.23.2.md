## 修复

- 分开任务行更新和页头失效。仅筛选范围、命令可见性／标签、语言／密度／主题测量条件或真实可用宽度变化重测。派生标题、HasIssueFilter及命令可用性按值变化通知，保留TaskFocus、清筛选和挂载改名。
- 同ID行、业务排序、终态及取消保持；普通进度只更新字段、进度及确实变化的IsEnabled，不清命令集合、不重挂按钮、不重建页面或替换ItemsSource。
- 共享协调器幂等，复用测量；相同决策不Clear/Add、不反复切标签或强制UpdateLayout。真实变化只作必要调整，有界处理SizeChanged／模板加载，不能固定整页、隐藏文字或关闭无障碍。
- 后台更新不关闭更多、不打断访问键提示、不抢焦点、不改变选择和滚动、不重置详情折叠。尺寸／语言确需移动命令时沿既有安全关层及异步重排，不能在旧Popup关闭栈重入。
- 核对PageCommandBarSizing及所有共享页，避免主区溢出转移反复Loaded／资源更新；保留23.0等高、背景、图标及黑边修正，全面样式合并留23.3。
- 详情固定ID原位更新，仅删除有证据的多余滚动恢复／测量；有效进度与调度保持。
- 历史尝试栏留白若23.1尚未提交则并入23.1，已提交则本版修，不回改。当前23.1已落盘拉伸，验证与提交后本版只做回归，保留正常内距、箭头、滚动、长标题及窄窗，不设固定宽度。
