## 实现及安全边界

- 应用拥有TasksQueueService；IMountingTask含不可变Priority／UTC SubmitTime及连接、文件、版本、依赖身份，IMountingConflict通过当前比较证明进入原条件取舍流程，IMountingObserver管理SQS、定时检测和固定意图观察。任务页只调用服务，页面释放不取消后台任务。
- 每挂载串行异步网络步骤、全局两路；严格优先级、提交时间及稳定序号。每优先级独立有界背压，低优先级不能占满高优先级入口。必要依赖、同版本共享读取及跨挂载共享配额继承优先级；持久上传／改名候选按用户请求和提交时间选择，不再隐式提升浅路径。
- 两协议实际传输均归入服务，协议方法分类留在各自模块。响应正文消费或关闭才归还执行位；范围、分页、分片请求边界重新调度，完整PUT／提交先安全结束。CFAPI父水合不占网络位，后台固定子读取继承P1，外部普通读取保持P0；缓冲只跨一个范围块并清零归还，不持根锁等队列／网络。
- 冲突、退避和路径依赖继续由现有事务保护；不新建重复持久写日志。SQS共享队列一个独立接收者，先整体校验及持久化再确认，存储核对重新进入挂载队列。C++ Shell本地缓存／完整本地解码不经网络队列。
- 服务展示当前阶段、优先级、进度、阻塞项和下次重试，原始错误独立保留；调度信息批量读取，避免每行查询SQLite。取消调用原业务所有者，取消不推断远端回滚；停止先封闭新工作和观察器，保留已接纳安全证明，排空后断开与释放。旧代次拒绝，不提前脱离未归还正文的处理器。
- 公共IPC v2、IFileSource、协议能力语义、产品SQLite表及配置／备份格式保持；.53可选密码和.hymcfg保留。
