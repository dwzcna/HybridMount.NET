## 实现边界

- 能力清单始终可展开；展开仅显示内存证据及后台读取的本地清理记录，原测试连接保持只读。检测按钮与完整写入提示常驻折叠区外，采用原生 DefaultButtonStyle，三协议 Expander 内操作按钮局部应用同一模板，紧凑删除按钮保持。
- 独立会话直接使用当前不可变草稿，不创建挂载配置，不要求本地目录。源和启用的 SQS 字段先校验；实际协议适配器、认证／TLS／重定向／元数据压缩及网络调度继续生效。单个用例三十秒，顺序依赖和明确跳过，失败不推广为整站不支持。
- WebDAV 实际目录／属性／配额／REPORT、拥有对象上的正文／范围、条件新建和更新、目录、删除、移动、锁及解锁；S3 实际 SDK 条件写、复制、分片初始化／上传／复制／完成／中止及版本清单核验；群晖实际发现、会话、共享／条目、拥有对象上的上传／同名保护、下载和 MD5、目录及专用清理。增强能力只使用实际观察到的证据；没有服务声明或响应时明确未观察到。
- SQS 只执行当前草稿的 GetQueueAttributes，不接收、隐藏或删除真实消息；Receive／Delete 明确标记本次跳过。
- 每次写前原子持久化独立检测日志，保存运行ID、范围摘要、精确路径、已知随机内容摘要及 ETag／VersionId／UploadId，不保存密码、密钥、认证头、会话或锁令牌。实际拥有路径按版本精确排除，未确认或内容改变的资源不凭名称认领。
- 取消停止新用例；应用接管在途工作，排空后使用独立六十秒清理令牌。强条件未验证、版本变化、丢失 UploadId 或权限故障保留资源及具体原因，取消后仍有遗留显示部分失败。界面提供逐次记录选择、可复制路径及只重试清理；关闭／重启不会自动重跑写测。
- 检测按钮与任务页均可取消；进度每250毫秒合并。任务历史保留公开结果和遗留路径；同一范围的实时证据与检测证据按具体路径合并，草稿输入／凭据代次和关闭拒绝迟到结果。
