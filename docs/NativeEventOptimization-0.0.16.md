# 0.0.16.0—0.0.16.3 实施计划

在0.0.15.0验证并本地提交后，按下列顺序重新检查代码；仅完整覆盖且有对应验证证据时跳过。当前.16.0／.16.1已实现并完成针对性验证；.16.2／.16.3仍待实施。实际结果见Validation-0.0.16.md。单执行者，不推送、不操作正式挂载、不重启Explorer；每版独立补丁、验证、记录、本地提交。.hmxbk、公共IPC v2和当前格式7的任务记录保持。

## 0.0.16.0：共享事件线程减负（0.5—1工作日）

activity／close在共享NativeRuntimeClient事件循环只处理有界内存状态并入队；关闭后的固定唤醒、本地变化、条目查询及根身份I/O移至每挂载串行消费者。EntryById已在.14替换，保留并复用结果，不能只凭此跳过版本。

保留绝对打开／关闭计数、代次和序号重验、改名删除因果与停止排空；重复关闭合并，队列有界，不按事件无限Task.Run。测试阻塞一个挂载消费者、共享循环继续接纳另一挂载、万次快照、旧序号和停止屏障。过载与业务失败升级范围先记录，.16.3再统一收窄。

## 0.0.16.1：文件操作恢复点查（0.5—1工作日）

FileTask以FindOperation(id)读取唯一恢复行，并核对MountId、条目和操作；保留原版本／本地身份及尝试供原核验器判断，不能为变化文件自动创建新尝试覆盖证据。重试入口同样按ID读取，不受页面100条历史限制。启动批量恢复仍可一次读取相关集合，不在每个新下载／释放重复执行LoadFileOperations。SQLite支持JSON表达式索引，本项优先复用现有主键，避免不必要的格式变更。

测试大历史下批量启动、跨挂载ID／条目不符、旧版本与身份、恢复尝试及历史上限；通过查询计划或计数验证按主键定位，不能只断言耗时。

## 0.0.16.2：一致的路径屏障（1—2工作日）

统一HasPendingRemote、RemoteDependenciesReadyCore及任务展示的祖先／子树边界。区分远端对象键身份与Windows本地映射：S3键继续大小写敏感；映射到同一本地路径的未决操作须保守阻塞，不能因大小写绕过保护。DAV／群晖以及未知协议不得推定为安全区分。

SQLite内置NOCASE只覆盖ASCII；选用与.NET OrdinalIgnoreCase一致的比较并配套索引／参数，避免用LIKE误解释%和_。覆盖非ASCII大小写、根目录、同名大小写、祖先、兄弟前缀、取消元数据、跨作用域及S3独立对象；检查上传发送和不可逆提交共用屏障。

## 0.0.16.3：单事件业务故障隔离（1—2工作日）

合法协议中的处理失败保留待办并按挂载有限退避／重试或可靠补扫；无法安全继续时停止受影响挂载，保留恢复证据，不销毁其他挂载共享运行时。过载显式隔离，不能丢事件后继续发布成功。

非法结构、无效字段、越界身份和协议破坏继续封闭不可信运行时；将解析验证与业务处理异常分开，不能把所有IOException都视为协议错误。测试瞬时DB失败后恢复、持续失败／积压、改名删除幂等、另一挂载正常、停止时重试排空、损坏协议仍熔断；故障诊断有界且不含秘密。

## 验证记录

各版先最小x64构建，针对性Debug／Release回归及差异／资源检查，再本地提交。最后版本补ARM64交叉编译和双架构签名包检查；真实Explorer／UI、Windows11 21H2、DSM及ARM64实机分别待测，不复用旧结果宣称通过。证据按00160-work至00163-work存入artifacts/validation/。
