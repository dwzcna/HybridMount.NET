## .54统一调度

用户进一步确认三条协作线：IMountingTask统一上传、下载、缩略图更新、删除、修改等执行工作；IMountingConflict保存需用户决策的冲突，决策后产生任务或受保护本地操作；IMountingObserver负责SQS、定时检测及服务器变化并提交任务／冲突。接口拼写规范为Conflict。任务含不可变Priority与UTC SubmitTime，优先级降序、提交时间升序，同时间以稳定序号保持确定次序。冲突不占执行名额，观察任务由统一服务管理生命周期。

应用创建并拥有Services/TasksQueueService.cs，挂载业务执行器注册到服务；TasksViewModel仅经服务取得快照与提交取消、重试、核对、冲突处理、副本及历史命令。服务拥有调度、依赖、优先级和可见状态，业务层继续拥有条件写入、恢复日志与事务，不建立第二套持久写入队列。

每挂载一个串行异步执行器，不占固定系统线程；同挂载存储网络步骤串行，上传下载互斥，跨挂载初始全局两路。P0用户打开文件按需读取，P1用户固定／下载／刷新／重试／确认冲突处理，P2自动上传／远端应用／改名事务，P3自动枚举与对账，P4可见远端预览，P5容量及非紧急维护。同级FIFO，必要依赖继承优先级；可运行高优先级到达后不再开始低优先级步骤。

范围块、分页和分片在安全边界让路；不可中断PUT／提交先安全结束或核对，不以取消推断回滚。响应正文消费／关闭后才归还执行位。水合父操作等待回调时不占回调名额，子读取继承优先级；等待队列、依赖或网络不持根锁，提交复核代次、身份和版本。冲突、退避与依赖任务释放执行位，无关路径继续；同路径和父删除／改名／未知结果仍保护。

覆盖挂载连接探测、协议HTTP／SDK、枚举、读写、目录修改、预览、容量、恢复与维护，审计直接调用旁路。SQS是统一服务管理的独立监听，同共享队列一个receiver，不占存储执行位，提示核对回挂载队列，持久化后确认。C++ Shell缓存与本地解码保持无网络队列／取图IPC。

内部描述含任务ID、挂载ID、连接代次、文件身份／版本、优先级及依赖；展示阶段、进度、让路原因、阻塞ID／路径及重试时间，当前等待与原错误分开。持久事务沿原记录恢复，瞬时需求按当前会话重建，合并重复任务并拒绝旧代次。公共IPC v2兼容。退出顺序：拒绝新增、停止生产者／监听、取消排队、安全收尾、断开运行时、释放仓库和服务。
