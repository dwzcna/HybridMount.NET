# 0.0.23.0｜工具栏底色、图标与设置页按钮统一

2026-11-15按用户要求收录本轮界面反馈，接在0.0.22.1之后。当前仅归档计划，代码与界面验证均未开始，尚未发送实施指令。产品版本在实施阶段统一更新；保全已有修改，默认本地提交、不推送、不安装生产包。

## 1. 页面顶部工具栏底色

- 各页左侧Segmented和右侧ButtonBar／CommandBar采用一致的主题底色与圆角，维持0.0.20.4确定的等高规则：以左侧Segmented自然高度为参照；右侧命令组继续靠页面可用区域的右边界。
- 统一主条在普通、悬停、按下、禁用和展开“更多”时的背景层次。单个按钮保留交互反馈，展开菜单时主条底色不应整体变黑或出现另一块不协调的底板。
- 核对实际模板和视觉状态覆盖，不能仅给两侧外层指定同一个Brush便判定完成。当前SharedStyles.xaml已让两侧外层使用同一资源，截图中的展开状态差异仍需运行时核实。
- 用户已认可弹出菜单本身：沿用其背景、阴影、行样式、图标尺寸、溢出行为和键盘操作。本版只处理主工具栏的视觉一致性。

## 2. 主条与设置按钮的图标

- 统一左侧Segmented、右侧主命令区和设置卡片操作按钮的图标实际显示大小、垂直居中和图文间距；以现有左侧图标的视觉大小为参照，保留原有图标语义及文字字号。
- 同步核对SymbolIcon、FontIcon、AppBarButton模板内的Viewbox和TaskHistoryButton复合图标，避免容器尺寸相同而实际字形仍被不同缩放。
- 高度与图标大小分别处理，不通过拉高左侧、裁剪内容或缩放整条工具栏实现一致。保留标准／紧凑密度和文字缩放适配。
- 主区命令进入溢出菜单时继续采用菜单自身的尺寸与样式，不把主条图标规则覆盖到菜单。

## 3. 设置卡片使用独立按钮

设置页操作统一为有独立底色的“图标＋文字”按钮：

| 区域 | 按钮排列 |
|---|---|
| 启动与托盘 | 独立的“打开 Windows 启动设置” |
| 云操作线程数 | 独立的“保存”，与其他设置按钮使用同一套样式 |
| 离线缓存 | “保存上限”和“立即检查回收”各自独立，之间保留明确间距 |
| 还原 | “移除所有挂载点”和“清空所有程序设置”各自独立，之间保留明确间距 |

- 每个按钮各自拥有底色、圆角和边框，不再让一整块背景把两个操作连成一条。统一高度、内边距、图标与文字间距以及悬停／按下／禁用／焦点状态。
- 设置操作留在所属卡片内并整体靠右；窄窗口和长译文允许按原顺序换行，不裁剪文字或引入横向滚动。
- 保留现有Click／Command绑定、CanExecute／IsEnabled、忙碌状态、确认弹窗、任务接管及可访问名称。“移除”和“清空”的行为与确认流程保持。
- 页面顶部工具栏继续保留分组和原生溢出；设置卡片通过显式共享样式使用独立按钮。避免扩大隐式Button／AppBarButton样式的影响范围。

## 4. 实施位置与范围

- 共享主题色、图标尺寸和按钮资源归HybridMount/Resources/SharedStyles.xaml；布局适配归HybridMount/UI；页面声明归HybridMount/Views/Pages。命名沿用UI／UserInterface及根AGENTS.md的分层约定。
- 重点核对PageCommandBarSizing、HeaderLayoutCoordinator／HeaderLayoutPolicy、TaskHistoryButton以及TasksPage、LogsPage、SettingsPage和其余页面主工具栏；按实际需要修改，不重做既有布局机制。
- 保留标题间距、日志筛选分行、页面完整宽度和菜单布局。本版范围为视觉与必要的布局适配，不涉及协议、同步、任务执行、SQLite、备份格式、公共IPC、包身份及Ext／Stock原生源码调整。
