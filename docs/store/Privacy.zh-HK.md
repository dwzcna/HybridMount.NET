# HybridMount.NET 私隱政策

發行者：RyleD。文稿更新日期：2026-11-16。本文適用於 HybridMount.NET 的 Store、側載及目錄發行；各發行形式使用相同的檔案同步功能。

## 處理哪些資料

HybridMount.NET 將你選擇的 WebDAV、S3 相容儲存或群暉服務連接至本機資料夾。為完成連線、檔案讀取、同步和錯誤復原，應用程式處理伺服器位址、掛載路徑、檔案與資料夾名稱、內容、大小、時間、版本、權限、工作狀態，以及你提供或授權使用的帳戶、密碼、存取金鑰和權杖。

應用程式不要求註冊發行者帳戶。應用程式本身沒有向 RyleD 自動上傳檔案、帳戶或診斷記錄的功能。你選擇的儲存服務仍會收到完成操作所需的資料；其儲存位置、保留規則及使用政策由相應服務供應商決定。

## 網絡連線與使用者操作

連線、讀取目錄、下載、同步本機修改和遠端變更會與所選服務通訊。啟用自動連線、遠端偵測或 SQS 事件功能時，相應活動可以在主視窗隱藏後繼續。關閉主視窗可能只是隱藏至系統匣；真正結束應用程式才會停止其背景連線。

「測試連線」使用唯讀查詢；「偵測所有能力」可在所選遠端目錄建立、修改和刪除測試資源。取消偵測後應用程式會嘗試清理；如清理失敗，會列出需要處理的具體資源。已送出的寫入不會因取消而自動復原。

系統 DNS、Proxy、憑證驗證以及你選擇的 AWS 預設憑證鏈可能存取各自的服務。啟用預設憑證鏈時，AWS SDK 按你設定的環境、憑證檔案或角色來源取得授權。Microsoft Store、Windows 和服務供應商可能依據各自的政策處理安裝、診斷或服務記錄。

## 本機儲存與保護

設定、索引、工作與復原記錄、檔案快取、縮圖和診斷儲存於目前 Windows 使用者可存取的本機位置。使用者選定的掛載目錄也會儲存檔案或預留位置檔案。應用程式以目前 Windows 使用者的 DPAPI 保護儲存的服務憑證；這不表示所有本機檔案、快取或記錄均已加密。

上傳、衝突或結果尚未確定時，應用程式可能保留快照以保護檔案內容。一般應用程式記錄按最長 30 天及最多 10,000 筆清理；生命週期診斷和復原記錄使用各自的保留規則。記錄與診斷可能包含檔案路徑、伺服器相關資料、時間、錯誤、程序或使用者識別資料，分享前請先檢查內容。

## 設定備份與診斷分享

匯出的 `.hmxbk` 可包含伺服器位址、路徑、使用者名稱、密碼及存取金鑰。未設定備份密碼時，備份中的憑證為明文；設定密碼後，使用 PBKDF2-SHA256 與 AES-256-GCM 保護憑證部分，伺服器位址、名稱和其他設定仍然可見。備份不包含檔案內容、同步索引或工作復原快照。

即使備份已設定密碼，匯入時仍請重新核對伺服器位址和設定。複製、匯出或向支援人員傳送記錄和備份由你主動執行；請只提供排查所需的資料，並妥善保管備份密碼。

## 傳輸安全

建議使用 HTTPS。HTTPS 使用系統 TLS 能力及應用程式的憑證驗證規則；如使用憑證指紋，請透過可信渠道確認指紋。你明確選擇 HTTP 時，傳輸不受 TLS 加密保護。應用程式不能保證你選擇的伺服器、Proxy 或其他網絡參與方如何保護資料。

## 控制、保留與刪除

你可以中斷連線、調整自動連線和偵測、取消工作、移除掛載，以及按照應用程式提供的條件清除設定。移除掛載時，應閱讀所選方式的影響：「保留已快取的檔案」不會補下載尚未快取的內容；「不保留掛載點檔案」會刪除根目錄下的本機內容，包括本機修改。移除掛載操作本身不會刪除遠端檔案。

如有未確認上傳、衝突或未完成的移除，應用程式可能阻止清理，以保留復原所需資料。取消不保證遠端已送出的操作會被撤銷。應用程式的清理不會刪除你另行匯出的備份或已分享給他人的副本。

解除安裝前，請處理未決工作、保存需要的本機內容並移除掛載。解除安裝可能刪除套件內的設定、憑證、快取和復原記錄；尚未下載的預留位置檔案需要重新設定服務後才能讀取。請勿將解除安裝或快取視作檔案備份。

## 聯絡與更新

如需查詢本政策或報告私隱問題，請透過本應用程式官方 Microsoft Store 產品頁列出的 RyleD 支援方式聯絡發行者。你可以決定在支援請求中提供哪些資料。

資料處理方式改變時，發行者會更新本政策及相應公開說明。發行者不會代替你所選的儲存服務處理遠端帳戶或遠端資料的刪除請求。
