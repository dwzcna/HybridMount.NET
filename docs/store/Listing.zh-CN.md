# 简体中文商店文案

## 产品名称

HybridMount.NET

## 简短说明

将 WebDAV、S3 和群晖存储接入本地文件夹，在资源管理器中按需读取文件并查看同步任务。

## 详细说明

HybridMount.NET 是 Windows 桌面文件挂载与同步工具。连接你自己的 WebDAV、S3 兼容存储或群晖服务，将远端内容显示为本地文件夹中的占位文件，需要读取时再下载内容。

你可以在资源管理器中访问文件、保留文件供离线使用或释放已缓存空间，并在任务页查看连接、下载、上传和远端变更的进度、步骤及结果。遇到权限限制、冲突或写入结果不明确时，应用会保留需要处理的状态和本地保护信息。

应用提供连接测试和协议能力检测，帮助了解当前服务器与目录的实际支持情况。不同服务的权限和条件写入能力存在差异；部分操作可能被阻止或需要手动处理冲突。完整能力检测可能写入远端测试资源，运行前会显示提示。

软件免费，无内购。你需要自行提供可访问的服务及相应账号；应用不附送云端空间，服务提供方可能收取存储、请求或流量费用。

## 功能要点

- 支持 WebDAV、S3 兼容存储和独立群晖服务连接。
- 基于 Windows Cloud Files 的按需读取与本地文件夹集成。
- 每个下载任务独立控制，任务详情展示实际步骤和逐文件结果。
- 可查看同步问题、权限限制和冲突，并按实际情况重试或处理。
- 支持挂载配置导入导出，以及仅保留已缓存文件的挂载移除方式。
- 提供简体中文、繁体中文和英文界面。

## 购买前／安装前须知

- Windows 11 21H2 或更高版本，x64 或 ARM64；挂载目录需满足本地 NTFS 及 Windows Cloud Files 条件。
- 需要你有权访问的服务器和网络连接。HTTPS 推荐使用；仅联机文件在离线或应用退出时不能凭占位文件直接读取正文。
- 上传、改名、删除和同步能力取决于服务权限及可靠的服务器保护机制，不能保证兼容每一种服务器配置。
- 关闭窗口默认隐藏到托盘；可从托盘真正退出。开机启动由用户设置。
- 卸载前请保存需要的本地内容并移除挂载。配置备份不包含文件正文。
