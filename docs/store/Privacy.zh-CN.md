# HybridMount.NET 隐私政策

发布者：RyleD。文稿更新日期：2026-11-16。本文适用于 HybridMount.NET 的 Store、侧载及目录发行；各发行形式使用相同的文件同步功能。

## 处理哪些信息

HybridMount.NET 将你选择的 WebDAV、S3 兼容存储或群晖服务连接到本地文件夹。为完成连接、文件读取、同步和错误恢复，应用处理服务器地址、挂载路径、文件与目录名称、内容、大小、时间、版本、权限、任务状态，以及你提供或授权使用的账号、密码、访问密钥和令牌。

应用不要求注册发布者账号。应用自身不设置向 RyleD 自动上传文件、账号或诊断日志的功能。你选择的存储服务仍会接收完成操作所需的数据；它们的存储位置、保留规则及使用政策由相应服务提供方决定。

## 网络连接与用户操作

连接、读取目录、下载、同步本地修改和远端变化会与所选服务通信。启用自动连接、远端检测或 SQS 事件功能时，相应活动可以在主窗口隐藏后继续。关闭主窗口可能只是隐藏到托盘；真正退出应用才会停止其后台连接。

“测试连接”使用只读查询；“检测所有能力”可在所选远端目录创建、修改和删除测试资源。取消检测后应用尝试清理；若清理失败，会报告需要处理的具体资源。已发送的写入不因取消而自动回滚。

系统 DNS、代理、证书验证以及你选择的 AWS 默认凭据链可能访问其各自的服务。启用默认凭据链时，AWS SDK 按你配置的环境、凭据文件或角色来源取得授权。Microsoft Store、Windows 和服务提供方可能依据各自的政策处理安装、诊断或服务记录。

## 本地保存与保护

配置、索引、任务与恢复记录、文件缓存、缩略图和诊断保存在当前 Windows 用户可访问的本地位置。用户选定的挂载目录中也保存文件或占位文件。应用以当前 Windows 用户的 DPAPI 保护保存的服务凭据；这不等于将所有本地文件、缓存或日志加密。

上传、冲突或结果尚未确定时，应用可能保留快照以保护文件内容。普通应用日志按最长 30 天及最多 10,000 条清理；生命周期诊断和恢复记录使用各自的保留规则。日志与诊断可能包含文件路径、服务器相关信息、时间、错误、进程或用户标识，请在分享前检查内容。

## 配置备份与诊断分享

导出的 `.hmxbk` 可包含服务器地址、路径、用户名、密码及访问密钥。未设置备份密码时，备份中的凭据是明文；设置密码后使用 PBKDF2-SHA256 与 AES-256-GCM 保护凭据部分，服务器地址、名称和其他配置仍可见。备份不包含文件正文、同步索引或任务恢复快照。

导入时请重新核对服务器地址和配置，即使备份设置了密码。复制、导出或向支持人员发送日志和备份由你主动执行；请只提供排查所需的信息，并妥善保管备份密码。

## 传输安全

建议使用 HTTPS。HTTPS 使用系统 TLS 能力及应用的证书校验规则；如使用证书指纹，请通过可信渠道确认指纹。你明确选择 HTTP 时，传输不受 TLS 加密保护。应用不能保证你选择的服务器、代理或其他网络参与方如何保护数据。

## 控制、保留与删除

你可以断开连接、调整自动连接和检测、取消任务、移除挂载及按应用提供的条件清除设置。移除挂载时应阅读所选方式的影响：“保留已缓存的文件”不会补下载未缓存内容；“不保留挂载点文件”会删除根目录下本地内容，包括本地修改。移除挂载操作本身不删除远端文件。

存在未确认上传、冲突或未完成移除时，应用可能阻止清理以保留恢复所需信息。取消不保证远端已发送操作被撤销。应用清理不会删除你另行导出的备份或已经分享给他人的副本。

卸载前请处理未决任务、保存需要的本地内容并移除挂载。卸载可能删除包内配置、凭据、缓存和恢复记录；尚未下载的占位文件需要重新配置服务后才能读取。不要把卸载或缓存当作文件备份。

## 联系与更新

如需询问本政策或报告隐私问题，请通过本应用官方 Microsoft Store 产品页列出的 RyleD 支持方式联系发布者。支持请求由你决定提供哪些信息。

当数据处理方式变化时，发布者会更新本政策及相应公开说明。发布者不代替你所选存储服务处理远端账号或远端数据的删除请求。
