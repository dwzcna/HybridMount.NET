# 繁體中文商店文案

## 產品名稱

HybridMount.NET

## 簡短說明

將 WebDAV、S3 和群暉儲存連接至本機資料夾，在檔案總管中按需讀取檔案並查看同步工作。

## 詳細說明

HybridMount.NET 是 Windows 桌面檔案掛載與同步工具。連接你自己的 WebDAV、S3 相容儲存或群暉服務，將遠端內容顯示為本機資料夾中的預留位置檔案，需要讀取時才下載內容。

你可以在檔案總管中存取檔案、保留檔案以供離線使用或釋放已快取空間，並在工作頁查看連線、下載、上傳和遠端變更的進度、步驟及結果。遇到權限限制、衝突或寫入結果不明時，應用程式會保留需要處理的狀態和本機保護資料。

應用程式提供連線測試和協定能力偵測，協助你了解目前伺服器與目錄的實際支援情況。不同服務的權限和條件寫入能力存在差異；部分操作可能被阻止，或需要手動處理衝突。完整能力偵測可能寫入遠端測試資源，執行前會顯示提示。

軟件免費，沒有應用程式內購買。你需要自行提供可存取的服務及相應帳戶；應用程式不附送雲端空間，服務供應商可能收取儲存、請求或流量費用。

## 功能重點

- 支援 WebDAV、S3 相容儲存和獨立群暉服務連線。
- 基於 Windows Cloud Files 的按需讀取與本機資料夾整合。
- 每個下載工作可獨立控制，工作詳情顯示實際步驟和逐檔結果。
- 可查看同步問題、權限限制和衝突，並按實際情況重試或處理。
- 支援掛載設定匯入匯出，以及僅保留已快取檔案的掛載移除方式。
- 提供簡體中文、繁體中文和英文介面。

## 安裝前須知

- Windows 11 21H2 或更新版本，x64 或 ARM64；掛載目錄須符合本機 NTFS 及 Windows Cloud Files 條件。
- 需要你有權存取的伺服器和網絡連線。建議使用 HTTPS；僅限連線的檔案在離線或應用程式結束時，不能單憑預留位置讀取內容。
- 上傳、重新命名、刪除和同步能力取決於服務權限及可靠的伺服器保護機制，不能保證相容每種伺服器設定。
- 關閉視窗預設隱藏至系統匣；可從系統匣真正結束。開機啟動由使用者設定。
- 解除安裝前，請保存需要的本機內容並移除掛載。設定備份不包含檔案內容。
