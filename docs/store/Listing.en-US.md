# English Store listing copy

## Product name

HybridMount.NET

## Short description

Connect WebDAV, S3, and Synology storage to local folders, access files on demand in File Explorer, and track synchronization tasks.

## Description

HybridMount.NET is a Windows desktop tool for mounting and synchronizing remote files. Connect your own WebDAV, S3-compatible storage, or Synology service to a local folder. Remote content appears as placeholders, with file contents downloaded when needed.

Access files in File Explorer, keep files available offline, or release cached space. The task page shows the progress, steps, and results of connections, downloads, uploads, and remote changes. When permissions, conflicts, or uncertain write outcomes require attention, the app keeps the relevant task state and local protection information.

Connection tests and protocol capability detection help you understand what your current server and folder actually support. Permissions and conditional write protection vary between services; some operations may be blocked or require you to resolve a conflict. Full capability detection may write remote test resources and displays a notice before you run it.

The app is free and has no in-app purchases. You provide your own reachable storage service and account. Cloud storage is not included; your service provider may charge for storage, requests, or data transfer.

## Features

- WebDAV, S3-compatible storage, and a dedicated Synology connection option.
- On-demand file access and local folder integration through Windows Cloud Files.
- Individually controlled download tasks with actual steps and per-file results.
- Visibility into synchronization issues, permission restrictions, and conflicts.
- Mount configuration import and export, plus removal that preserves cached files without downloading uncached content.
- Simplified Chinese, Traditional Chinese, and English interfaces.

## Requirements and important information

- Windows 11 version 21H2 or later on x64 or ARM64. Mount folders must meet local NTFS and Windows Cloud Files requirements.
- A reachable server that you are authorized to access. HTTPS is recommended. Online-only placeholders cannot provide uncached contents while offline or after the app exits.
- Upload, rename, deletion, and synchronization depend on service permissions and reliable server protection mechanisms. Not every server configuration supports every operation.
- Closing the main window hides it to the system tray by default. Use the tray to exit. Startup at sign-in is controlled by the user.
- Save local content you need and remove mounts before uninstalling. Configuration backups do not contain file contents.
