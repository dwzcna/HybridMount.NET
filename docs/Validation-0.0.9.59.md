基于88955eb（0.0.9.58），分支codex/native-backend；保留四工程、HybridMount.exe及NativePreview身份。使用global.json固定SDK与本机VS2026、Windows SDK；仅本地提交，不推送或修改master，不重启Explorer，不补跑既有.33停止专项。

## 实现状态

- 计划所列代码已完成：原生异步本地队列64项、同身份／内容戳合并，内存图片128项／32MiB／两分钟；失败按版本冷却。COM不等待原媒体解码，冷／部分／零字节媒体只查缓存。数据库忙立即退让，一次请求共用只读事务及100ms期限。
- 采样复用专用MTA的IUIAutomation2，连接100ms、事务50ms；每视图最多128点／64媒体、父节点最多六层。实际工作预算200ms，调用250ms；变化250ms合并、静止五秒补查、超时五秒／连续三十秒退避。无效视图保留旧需求，接受其他有效视图及已核验的部分命中。
- 托管全局单项生成，执行前一次检查四帧缓存；原生／托管按SID及NTFS身份共享Mutex，先取得Mutex再取得正文保护租约。原图只解码一次256像素，内存派生32／64／128；低CPU／I/O优先级、原有Job、读取预算及期限继续保留，远端仍走P4调度。
- C#是唯一持久缓存写入者；原生队列仅内存保存。两条生成路径均250ms合并单文件通知，每秒最多八项，同路径保留最新版本；通知及返回前检查授权、身份和内容戳。解码回执提供缓存戳，避免把旧PNG挂到解码退出后出现的新内容上。
- 原宿主ABI保留，新增内部活动回调覆盖工作／通知存活和退出收尾；进程内DLL回退只查持久缓存。公共IPC v2、配置及数据库格式不变。
- 按用户同期TasksPage.xaml调整代码后置，去除已不存在的HistoryToolbar引用；操作统一为普通Button＋FontIcon，菜单／事件、悬停提示和中文无障碍名称保留。每行恢复任务ID并支持选中复制。

## 阶段失败及修正

- 早期回归73项中的2项失败，随后22项中的1项失败：通知等待窗口过短，以及只读保护句柄关闭推进USN后重复排队。修正关闭后最终戳校验、进程退出确认、同身份在途合并及测试等待，最终异步及双配置相关通过。早期日志和async-proof系列保留。
- Release首轮1553/1554：新宿主加载旧Release扩展，找不到新增内部导出而提前退出。补齐生产Release构建后，广泛1554/1554通过。
- 独立包前两轮浏览生成超时：第二轮证据显示空白点回溯耗尽250ms预算，已找到的项目随无效整轮被丢弃。缩短容器回溯、预留返回时间，并合并有效命中／保留不确定需求后第三轮通过。
- 退出验收初版错误地把已退出但仍有进程对象的情况当成仍在运行，改为验证HasExited；本地内容冷却测试的原地写入曾暴露临时内容版本、得到额外失败，改用原子替换提供稳定新版本。原日志保留，最终78/78及实际COM通过。
- 冷启动辅助脚本初次here-string嵌套解析失败，未执行应用动作；改为从已验证脚本生成后，冷宿主完整验收通过。
