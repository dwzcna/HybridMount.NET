## 实现

- Explorer观察改为仅读取已经呈现的UIA视口；不调用Realize、焦点、选择或滚动写入。需求稳定排序去重，无效采样保留需求。预览GET仅探测安全quoted ETag候选，逐响应仍验证实际合法强标签、206及准确范围；普通写条件不变。
- 不支持格式、可靠范围缺失及预算耗尽返回明确状态；首窗口失败不启动解码器。缓存发布与取消共用屏障，使用异步可合并单文件通知。三个预览后台启动入口关闭启动反馈；托管启动器使用挂起创建、三个继承管道白名单、先加入受限Job再恢复。
- 纯目录属性观测核验类型、映射、CFAPI身份、干净状态及目录自身意图；子文件修改不升级为子树冲突。取消历史通过只读核对证明无害后解除误依赖，保留原取消和版本。删除、类型变化和未知写入继续保护。
- 固定属性通知优先处理路径，启动、溢出及必要恢复分批补扫。资源归还唤醒对应文件；同批未获得下载名额的固定需求保留到活动下载结束，避免等待30秒补扫。释放继续保护本地修改、排除及真实未决事务。
- 任务页分别显示当前等待／阻塞任务及原始错误；清理历史保留持久依赖，上传／远端更新可只读重新核对，不授权覆盖或重发。
- 实际收尾发现策略高位enum以负数传输导致GetUInt32异常；原生显式输出uint32，托管兼容合法int32位模式并拒绝越界值。
