## 实现

648个展示资源键随包提供zh-CN／en-US／zh-HK RESW／PRI。统一服务在XAML创建前读取同部署UiLanguage；保存失败维持原快照，未知值按system且不回写。系统模式读取GetUserPreferredUILanguages真实优先列表，通知与窗口激活复核。未改变CurrentCulture，格式化按Windows区域；香港译文采用檔案、資料夾、網絡、上載及快取等用语，完整人工语境审校仍待进行。

附加资源绑定在原控件上更新，页面缓存、表单草稿与滚动保留；程序化消息保存键和参数，原文使用Raw。六个消息渠道独立保存打开状态及严重程度，同文主动发布可重开，语言／后台刷新不重新发布。弱订阅、卸载与Dispose屏障拒绝迟到更新。备份行、任务详情、通知条及遗留目录列表补齐动态显示。

原生代码不引入CLR。菜单热路径只读不可变内存和预先打开的64字节摘要，后台按SID／Session／包Family建立映射、加载MUI并读取偏好；奇偶代次防部分写入，未知协议／LCID保留原有效缓存。后台持模块引用，任务结束释放，不保留常驻语言线程。无主程序时按已保存选择或真实Windows列表刷新；三套MUI按目标架构生成。注册时状态列文案使用同语言缓存，已有Explorer／安装显示名称的系统缓存没有冒称即时刷新。

build/Test-Localization.ps1阻止缺键、重复键、参数或原生文字漂移；构建检查源码契约，交付包检查实际PRI及MUI、架构和无CLR。公共IPC v2、配置、SQLite及备份格式保持兼容，新增UiLanguage为独立REG_SZ。
