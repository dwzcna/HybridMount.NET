# 0.0.13.0 验收记录

本版基于 `master` 的 `e5e6ffe`（0.0.12.0），只处理备份格式及相关界面，保留四工程和安装身份。证据目录：`artifacts/validation/00130-work/`；机器可读汇总：`build-delivery-summary.json`。

## 已实现

- `.hmxbk` 缩进 UTF-8 JSON，固定格式标识与独立结构版本；旧 HMCONFIG v1—v6 外部备份停止支持，改名也拒绝。
- 无密码全部明文，有密码使用 PBKDF2-HMAC-SHA256／600,000 次迭代和 AES-256-GCM 逐项保护主凭据及独立 SQS 凭据；非敏感字段可手工编辑。详细参数与迁移步骤见 [配置备份说明](ConfigurationBackup.md)。
- 有界读取会话，识别与密码重试使用同一文件快照；严格字段、结构和加密参数检查。关闭、取消和退出清理会话、密码输入及可清理缓冲；在途解密持有租用，最后归还后清零。
- 导出默认不保护并提示明文风险；无密码导入直接预览，有密码才显示密码框，支持错误后重试。退出立即停止接纳、取消操作和清空输入，等待已开始的操作收尾。
- 三语言资源各 1082 键；原本机配置／DPAPI 迁移、公共 IPC v2 和 SQLite 表结构保持。导入只新增、不自动连接、不访问远端。
