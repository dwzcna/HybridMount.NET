# HybridMount 0.0.8 验收记录

2026-11-03—04，Windows x64，.NET SDK 10.0.401／VS 2026／Windows SDK 26100。产品 0.0.8，程序集／扩展／测试／MSIX 0.0.8.0。预算 12–20 小时，真实服务及 GUI／实机等待另计；保留三个工程、现有 AWSSDK.S3、IPC v2 与正式缩略图门控。

## 已完成

- S3 全前缀 ListObjectsV2 收齐所有分页后建立完整快照，变化 HEAD 核对 ETag／长度／时间并取得 VersionId；缺失再 HEAD 和虚拟目录前缀确认，403／失败／取消不作删除。ETag 不作 MD5，列表令牌不作增量游标。
- S3 每挂载独立自动检测，默认开启及 300 秒完整对账；全局两根，从上一轮结束计时，不叠加。网络锁外、提交重验会话和根，复用 0.0.7 原生固定更新、上传回显、本地保护和删除屏障。
- 用户追加的立即重扫：仅只读观测变化触发从第一页重做，最多连续三轮；持续变化保持连接，后台 5 秒后继续，取消及时结束。真实写入冲突不因此重发。兼容列表毫秒和 HTTP HEAD 整秒，保留精确列表时间，不误判同一对象为持续变化。
- AWSSDK.SQS 4.0.100.21（Apache-2.0），与既有 S3 共用 Core 4.0.102.14。AWS 同区域 Standard Queue，默认关闭、20 秒长轮询，同进程同队列单接收器。全部相关记录整体校验并持久后确认，Key 一次解码、同 Key sequencer 去重乱序，消息只是当前状态查询提示。
- SQLite v6 扫描批次、提示、去重及待应用重放；旧凭据 scope 退役未发送提示，原生不可逆提交保留保护。独立队列凭据 DPAPI，设置与状态／最近事件／待核对数，属性测试只读且零消费。备份 v3 带 SQS 选项及加密凭据，兼容 v1/v2，导入只保存。
