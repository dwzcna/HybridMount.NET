# 0.0.22.0｜源码目录规整、测试精简与开发规范

以已完成的 0.0.21.0 为基线，覆盖主程序、测试、原生后台和 Explorer 扩展四个工程；逐批迁移、编译、必要回归及独立本地提交。保全进行中的用户修改，不推送、不安装生产包、不操作正式挂载或重启 Explorer。源码整理预计 4—7 工作日，构建、人工与设备另计。

## 目录与依赖

保留 Commons 目录及 HybridMount.Commons 根命名空间，可按功能增加子目录／子命名空间。**不新增 Abstractions 或替代转发命名空间。** 新增 Infrastructure；四工程名称、输出、包身份、COM／ABI、数据库、配置及 IPC 格式保持。

- ViewModels：真正的页面、列表、编辑器与绑定状态，类型使用 ViewModel 后缀；DTO、枚举、格式化和持久化移出。
- Views/Pages、Views/Windows、Views/Dialogs：页面、窗口和弹窗及视图代码。Controls 为可复用控件。UI 放格式化、转换器、布局行为、界面绑定和 WinUI 适配。
- Models：纯业务数据、值对象、枚举、快照与纯规则。Commons：接口及边界契约，可引用 Models，二者不依赖 Services、Infrastructure 或 UI。
- Services：连接、同步、任务、移除、恢复等编排，经 Commons 契约访问基础设施。
- Infrastructure：协议、数据库、文件系统、凭据、Windows／CFAPI、原生进程及 IPC 的具体实现，不反向调用具体业务服务，通过接口／回调／事件交互。
- Composition：装配、入口配置与生命周期接线，保持现有装配方式，不新增 DI 框架。Helpers 仅放依赖基础库的通用小工具。

拆分接口具体系统操作、模型资源渲染、导航 WinUI 绑定、设置／恢复系统操作；语义消息和资源渲染分开。在数据库、文件操作、原生会话等真实边界提取必要接口，保持事务、锁、句柄、取消与释放顺序。收紧跨层 GlobalUsings，命名空间与目录一致，同一 partial 类型集中。同步 XAML、资源和编译登记。

Stock 按运行时、CFAPI、文件系统、预览、缩略图、IPC、诊断及资源归类；Ext 按 COM、菜单、缩略图、预览、IPC 及资源归类。身份、语言及缩略图基础代码归 NativeShared，两工程编译同一份源码，不新增工程或复制实现。更新头文件、RC、项目与脚本，保留 ABI。

## 测试与长期规范

保留单一测试工程，按 Unit、Integration、Native、Architecture、Fixtures、Acceptance、Assets 及功能分类。抽取重复 HTTP、协议、目录、数据库、原生宿主与等待设施，保持每项状态和并发隔离。相同路径仅输入不同的用例参数化；独立竞态、取消、恢复和数据保护保留。删并逐项记录替代覆盖或失效原因，不设机械删减比例。

按功能目录集中维护生产源码链接与排除，验证不漏编、重复编译或误引入 WinUI／生成入口。合并旧目录／内部名称／实现文本断言，保留行为与外部契约检查。纯逻辑、本地集成、原生集成提供明确分组；真实服务和长时验收显式执行，完整门禁保持。记录前后源码规模、夹具、有效场景及运行耗时。

新增根 AGENTS.md，明确目录判断、依赖、类型／文件／命名空间、partial、Commons、NativeShared／第三方、测试复用、移动后同步登记和保全规则。集中结构检查覆盖目录／命名空间、禁止依赖、编译项与共享源码，接入构建；生成和第三方例外明确列出。
