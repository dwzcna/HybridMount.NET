# 0.0.23.3：主程序样式合并与统一

2026-11-15用户明确授权，经协调任务交接；按最新指令由23.2顺延至23.3，23.2已按新增指令完成刷新抖动修复。先完成0.0.23.0（含主条黑边）、0.0.23.1及0.0.23.2，再完整实施本版，分别验证、记录并本地提交。不推送、不安装生产包、不操作正式挂载、不重启Explorer。归档后继续实施，不停留在记录；清单以23.1最终代码为基准。

## 1. 目标与范围

.NET主程序页面、弹窗、复用控件及C#动态界面，合并重复定义，同时统一同类控件的尺寸、间距、圆角和图标规则。保留23.0／23.1最终验收结果、菜单外观、黑边修复和首页新布局；不改变业务流程、数据库、备份格式、公共IPC及原生源码。

## 2. 样式收敛

| 类别 | 规则 |
|---|---|
| 独立操作按钮 | 设置、首页、协议表单使用通用普通操作按钮样式，合并协议／设置重复定义 |
| 轻量操作 | 显式使用系统SubtleButtonStyle；取消普通Button默认透明的全局覆盖 |
| 工具栏命令 | 保留原生CommandBar／AppBarButton模板和溢出，主区共用外观资源 |
| 图标文字 | 主操作图标20 DIP、图文间距8 DIP；菜单、行内小操作和展示大图标保留各自用途 |
| 操作组 | 通用间距12 DIP；左右对齐由使用位置决定，不额外创建按钮样式 |
| 卡片标题提示 | 复用现有卡片、标题、InfoBar和错误提示，同类外观一个维护入口 |
| 列表容器 | 合并协议排除列表相同的拉伸／零内边距样式，挂载列表保留必要额外间距 |
| 任务状态 | 普通、错误、冲突共用基础模板，保留语义配色 |

普通按钮沿用23.0尺寸与主题圆角；工具栏仍按Segmented自然高度。等价页面／协议样式改为通用语义名称，一次更新XAML、C#、动态XAML和测试，删除旧键，不留转发别名。删除无引用、空包装及本地重复覆盖属性。布局位置、业务绑定、内容、事件留在使用处；不为单次组合新建Style。不同控件共享颜色尺寸，保留必要类型样式，不强行合并破坏行为。

## 3. 资源维护

共享样式集中HybridMount/Resources/SharedStyles.xaml，不新增按页样式文件。单页特殊模板留在页面。主题颜色继续ThemeResource，合并前核对作用域及明暗／高对比度差异。密度资源类型、寿命和逐键更新保持，不删除活跃资源、不替换字典或重建页面。C#动态界面引用同一资源，不复制颜色尺寸或转移到新工厂。

AGENTS.md追加长期规则：新增界面先复用；新增样式说明用途；同类外观集中维护；例外说明原因，命名UI／UserInterface。

## 4. 验证交付

以23.1最终代码建立清单，记录前后数量、旧新键映射和保留例外；自有Style数减少，完全重复及无意义转发清零。检查全部页面、三协议、备份、详情、冲突和动态弹窗，原绑定命令及引用完整。覆盖三语言、明暗／高对比度、标准／紧凑往返、宽窄、长文、悬停／按下／禁用／焦点／溢出。重点防回归黑边、图标、设置按钮连片、菜单及密度。

完成最小x64、Debug／Release定向、ARM64交叉构建及双架构签名包检查；真实交互、DPI、21H2和ARM64设备未执行明确待测。更新devplan、Changlog和验收文档，独立0.0.23.3本地提交。
