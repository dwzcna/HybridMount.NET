## 代码已完成

- 挂载卡片和两种协议完整配置窗口按实际清单绑定决定是否提供缩略图开关。需要同一 Application 的云入口、对应 COM 类和存在的包内 DLL；拒绝越界路径。无处理器或查询失败时隐藏入口，不覆写已保存偏好。打包身份不等于处理器可用；非打包后台发现已安装入口时保留实验配置能力，实际根关联仍待验收。
- 图标溢出计算同时排除不可用入口，重算分组分隔符，卡片第三行固定高度保持；没有增加常驻说明小字。
- 完整诊断增加原生根水合策略、当前身份的 WinRT 可见性／AllowPinning、根 Shell AUMID、显式缩略图类、实际注册原因及预览队列状态。查询不联网、不读正文、不改固定或 InSync；新回归核对身份、占位、原生策略和请求数量保持。
- 独立临时 MSIX 使用随机 CLSID／管道，仅测试宏记录原生阶段。ShellIntegrationProbe 不作为普通 Fact；使用实际图像工厂 THUMBNAILONLY 和识别像素，不能以普通图标返回算通过。测试策略更新仅在测试编译，生产连接没有策略更新入口。
- 三个工程、SDK、IPC v2、SQLite、配置／备份格式和根 ID 保持，版本统一 0.0.9.32。
