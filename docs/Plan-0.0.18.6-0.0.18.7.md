## 检测服务与覆盖

独立显式编排服务复用实际适配器、云额度、期限、取消、证书、条件校验和临时清理；检测生命周期与证据分开。每个适用能力给结果或明确跳过原因，读先行、写对象依赖顺序，单项失败继续无依赖项。只在配置根及本次专用资源，不遍历整站写测；使用前置IPv4、摘要、权限、gzip、重定向实际传输，不绕过业务安全。

- WebDAV：OPTIONS、HEAD／元数据、PROPFIND、配额、REPORT，拥有对象上的GET、Range、PUT、条件新建／更新、MKCOL、DELETE、MOVE、Overwrite、LOCK／UNLOCK；错误If-Match仅用于拥有对象，释放锁。同步增强四项实际证据，没摘要／权限／gzip或301／308不伪造支持；同步令牌先规范初始化，无前提则说明。
- S3：ListObjectsV2、Head／Get／Range、Put与条件创建／更新、Delete及条件、Copy源／目标条件；真实有界multipart创建、上传分片、分片复制、完成／条件完成、中止，不用小Put代替、不整文件入内存。记录UploadId及VersionId，版本桶逐版清理，删除当前键不足以宣称零残留。
- Synology：发现、登录／注销、目录／条目、共享、下载、MD5、上传／overwrite=false／建目录，仅拥有对象删除；不扩展对用户文件覆盖删除移动的授权。
- SQS依据草稿，不仅已保存挂载。GetQueueAttributes及真实运行证据可读；不接收／隐藏／删除真实队列消息，不改配置；Receive／Delete需真实事件，明确本次跳过。

## 取消、临时归属、清理和日志

高随机运行ID及允许的专用名；写前持久清理意图，记录范围指纹、协议／路径、内容哈希／长度、版本／ETag、UploadId、锁归属及阶段，明确未知结果／冲突／待清理，不能靠前缀认领。扩展原临时日志以独立探测会话归属，未保存草稿不建假挂载或静默存全表单。日志无明文密钥／密码／认证头；未保存认证重启需用户提供匹配范围凭据。重启仅恢复清理／展示，绝不自动重跑写测。活动挂载按运行ID归属排除产物，不当作用户内容同步。

取消立即不启动新例，有序收拢在途写入和结果，先排空写入再进入“正在清理测试文件”，避免清后又出现资源。取消不回滚已发生远端操作，未知结果依原归属核验。正常／失败／取消／关闭均用独立有界清理令牌处理拥有文件、目录、multipart、版本对象和锁，不能因检测令牌取消跳清理；清理失败不覆盖首个错误，响应／流／额度／会话／锁均归还。

每次均报告清理结果。未清理项逐项显示文件名、完整远端路径／对象键、VersionId／UploadId、具体原因和复制路径；已确认归属显示“请手动删除以下测试遗留文件”，归属不明显示“请核对后手动删除”。空目录和非文件资源准确分类，不只写日志或只报清理失败；关闭重启仍可在任务／清理记录查阅，支持安全重试并及时更新已清理状态。

全程在当前应用日志用同一运行ID关联开始、预检、能力、方法／脱敏目标、成功／拒绝／失败／跳过、耗时、取消、创建／归属、清理及汇总；保留HTTP／服务码与阶段，区分检测和清理失败。不得记密码、密钥、Authorization、认证会话／锁令牌、预签名URL敏感参数，文件名／远端路径仍可定位。写入拒绝除具体错误外显示准确提示：“部分写入测试失败，可能是测试目录未开放写入权限。”只作可能原因，不判整站不支持，区分403／AccessDenied与超时断线，其他只读与清理继续。
