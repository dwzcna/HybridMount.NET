# 0.0.25.1｜清理旧兼容并建立新数据基线

已授权接0.0.25.0独立实施、验证和本地提交。允许用户重新配置和建库，不授权应用自动删除旧数据；不推送、不安装生产包、不操作正式挂载或重启Explorer。

## 最新追加要求

到本版完整删除0.0.25.0的旧版本／旧包检测、安装清单扫描、启动拦截和弹窗，以及专用资源、接口、测试和失效登记。当前包身份、独立配置／根前缀与IPC2继续隔离数据和实例；不得为隔离重新加入旧版本探测。schema9对旧库、较新库、损坏及访问失败的必要错误不属于此次删除范围。0.0.25.0的历史实施和验收事实保留。

## 新基线

- SQLite直接创建schema9，不迁移7／8，不保留Upgradeable或旧库升级备份分支。只读预检分别报告旧版、较新、损坏和访问失败；拒绝时原库及文件保持，包含无DB但有旧配置的边界。
- 删除IPC1、旧实例锁／转发／响应；保留公共IPC2以及现有进程认证。
- 删除共享thumbnails.db迁移及旧缓存查找回退，只路由当前挂载GUID数据库。
- 删除LegacyRecoverySource、Source=null模拟源迁出、旧Enabled规则转换、缺字段推断、旧任务适配和历史格式补写；相关专用接口、资源、测试及登记逐项记录替代。
- .hmxbk schema1及凭据保护编码不变，导入建立新挂载身份，不恢复旧任务和根身份。

## 保留的安全行为

保留当前中断恢复、OutcomeUnknown、冲突、内容保护和移除收尾。当前版本也可能产生孤立注册，不能按“遗留”名称批量删除。保留WebDAV／S3／群晖服务端兼容、21H2及现行条件保护；不改COM／ABI、不重排Ext／Stock布局。
