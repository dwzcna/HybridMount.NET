## 远端批次与分类

批次为同一挂载、连接／凭据作用域的一次检测轮次。分页、子目录枚举、协议回退、内部256项分块不拆可见任务；不靠时间窗口，不跨轮、挂载、账号或连接。发现可与处理交叠；发现结束前显示已发现／已处理，不提前完成。旧失败／等待／恢复项保持批次归属；无变化不创建空任务。

- 新远端普通文件、已存在未水合文件的内容变化：创建／更新冷占位，归本批“应用远端更改”。
- 已完整水合或部分水合且远端内容变化：每个文件独立“文件下载”任务，完整下载核验新版本，保留原Pin设置。**不能合并下载**，每个下载可单独取消／重试。
- 仅权限等非内容属性变化：更新元数据，不因此下载正文。
- 本地修改、未确认上传、身份异常、占用：保留冲突／等待保护，不覆盖。
- 分类依据CFAPI实际状态、缓存范围及身份，不能仅Materialized／长度／Pin；零字节结合完整状态和水合历史，不能确认进入核验。已有明确固定意图及提交恢复继续原流程。
- 目录和删除沿用安全依赖；无需正文者归批次，删除不生成下载，本地内容保护保持。

## 执行、取消与恢复

批次有真实身份、生命周期、计数和取消，内部逐文件待办／版本／错误／恢复证据保留。批次阶段为读取变化、核对本地、创建／更新占位、提交索引、汇总；逐文件结果含新增／更新／删除／失败／跳过和原因。独立下载阶段含准备快照、下载、内容核验、应用新版本和提交索引，复用原生不可变快照安装和身份、固定、改动保护。

内部FETCH关联独立下载并读取已验证快照，不重复任务或源读取。占位提交前原生保护句柄重验身份／缓存范围／活动读取；此时已水合则原子转独立下载并调整计数，不按旧分类释放缓存。成员失败继续无依赖项，目录依赖、路径屏障、未知结果保护保持。

取消批次只停止其占位成员，保留完成结果，禁止同版本下一轮自动重排；独立下载不随批次隐式取消。重试仅未完成且符合条件成员，新增尝试，不重复成功项。扫描中断保留提交结果并标中断／部分失败，不用不完整列表推断删除。重启恢复批次及业务机制，清理父历史检查全部成员／恢复依赖。“同步问题／冲突”可定位具体文件，不隐藏错误。

连接、上传、刷新、下载、释放、三种移除及能力检测均接入真实阶段。

## 数据与接口

新增operation_runs、operation_steps，保存任务／尝试身份、代次、顺序、状态、时间、进度、原因和证据关联。现有task_steps／task_attempts继续控制Verified依赖，不作展示替换。重试保留历史；名称语义键、服务器错误原文。阶段边界及终态先持久化，普通进度250毫秒合并。类型化快照及按ID详情／变更接口，主列表不逐任务查库。

新增remote_task_batches、remote_task_batch_members。批次含挂载、连接作用域、检测身份、发现状态、展示任务及汇总。成员关联原pending ID，稳定顺序、类别、展示归属；业务证据仍在原pending。批次归属与远端事件／检查点同事务，快速创建和普通应用两路均覆盖；同项同版本复用，新版本保持代次和提交屏障。下载显示类型与原执行身份分离，取消／重试／核验按业务身份派发。索引查询与分页，不能反复序列化整批大JSON。

以.19最终版本为基准兼容增量升级，仍schema7时7→8。启动业务服务前一致性备份及事务升级，失败回滚保留原库。旧历史不按时间猜批次。MountIndexFormat严格预检须增加Upgradeable状态及升级流程，不能只改版本常量导致旧库打不开。公共IPC不变，原生内部核验随主程序同版。

ApplyRemoteItemAsync现以PinState==1或Committing／Hydrating决定下载，应改实际水合分类。Stock.applyRemoteSnapshot已接受pin、核验快照并持保护句柄，可复用；refreshPlaceholder须补冷占位／活动读取重验。InstallRemoteSnapshot及内部FETCH避免重复read卡片。
