## 实现边界

- 驱动写契约已实现，界面不自动上传或传播本地删除。
- 强 ETag 范围响应按版本验证；弱 ETag/时间仅是有限线索，完整 GET 缓存在会话内作为单个不可变快照，不能宣称服务器提供可靠随机版本读取。
- 首次写入会创建并清理 .hybridmount-probe-* 临时文件以验证条件。非空 WebDAV 目录删除拒绝。
- 固定、本地修改或活动项不自动更新/脱水；出现远端变化时保留旧本地内容并报告冲突，处理后刷新。
- 默认缓存为软限制，临时下载、固定和受保护内容可造成超限。不会自动解除固定；退出保留同步根。
