## 构建

- 可选性能记录保存阶段耗时、执行／复用状态及binlog。完整托管构建作为复用单位；实际文件集合、内容摘要、构建属性、工具链、还原资产及必要输出均一致才复用。
- 输入／输出变化、缺失或记录不完整执行官方完整链；缓存未命中使用官方Rebuild，保证内容变更但时间戳未变时也不带入旧产物。不修改SDK目标或改写生成文件时间戳，失败／取消不登记成功。
- VS快速生成输入覆盖C#、XAML、资源、项目、清单和原生依赖；成功标记与输入同组，稳定载荷用独立集合核验存在，避免旧时间戳持续使项目过期。脚本只构建Stock，沿用它已有Ext引用；原生完成后再评估托管内容。
- 启用SDK已有的Csc卫星生成路径，避免桌面MSBuild的AL输出在相同输入下产生不同语言DLL。
- 结构和资源门禁按内容与文件集合安全复用；每工程实际Compile登记独立核验，实际交付资源永远重新检查。
- TestOnly只准备测试及明确依赖；复杂或未知筛选回退完整夹具，原完整门禁与验收分组保留。NuGet自身增量还原只调用一次，复制跳过未变化文件。
- 架构、配置、部署、运行时、Shell、构建／打包／发布及测试变体隔离；同仓库脚本串行，测试原生产物独立。输出ZIP亦纳入完整结果保护。

## 发布

- 四个pubxml：win-x64、win-arm64自包含Full；win-x64-small、win-arm64-small依赖目标电脑预装同架构.NET 10和匹配的Windows App Runtime。默认Release非打包目录，保留当前目标框架与最低系统版本。
- RuntimeMode Full|Small默认Full；Package生成MSIX，Publish生成目录和ZIP，可依次执行。
- Full的SelfContained／WindowsAppSDKSelfContained均true，Small均false。关闭ReadyToRun、符号／文档复制、裁剪、AOT及单文件发布，保留应用依赖、SQLite、Stock、Ext、语言、许可证及必要引导。
- 交付目录、文件名和检查区分模式与架构，MSIX身份、Publisher和通道不变。核验Full实际框架载荷、Small共享框架／MSIX依赖及目录引导。
