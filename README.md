# HybridMount.NET

当前版本 **0.0.8.6**，面向 Windows 11 21H2 及以上，支持 x64／ARM64，使用 WinUI 3、.NET 10、MSIX 与 Windows Cloud Files API。

导航为“首页 → 挂载 → 任务 → 日志”，设置位于底部。设置标题固定在滚动区上方，选项卡片保持左侧对齐，宽屏限制内容列宽，窄窗口内控件随可用宽度收缩。挂载使用 MapDrive 图标；品牌资源采用银灰色硬盘与骡子探头图形，覆盖程序、托盘、扩展及 MSIX 全部缩放资源。

## 使用

1. 在挂载页点击“新增挂载 → WebDAV 或 S3 对象存储”，填写 HTTPS 服务器根、账号及应用密码，选择本地 NTFS 空目录，点击“创建并连接”。WebDAV 使用账号与应用密码；S3 填写 endpoint、bucket、prefix、region 和寻址方式，选择 SDK 默认凭据链或填写访问密钥/临时令牌。新增及编辑对话框底部固定显示“测试连接”，测试期间改为“取消测试”，结果在表单下方显示；测试不保存配置或注册根。us-east-1 是未验证默认区域，应按服务商说明确认。连接失败保留配置供重试；从未注册成功的挂载允许编辑服务器、桶和前缀，已注册挂载保持远端根限制。S3 错误会显示失败阶段、HTTP 状态、服务码、请求 ID 和服务端区域提示（如有）。
2. 在资源管理器浏览真实占位文件，打开时按需读取；“始终保留在设备上”固定并下载，“释放空间”解除固定并回收合格缓存。本地修改、新建、活动文件和状态不明项目受到保护。
3. 挂载页在列表中突出名称、状态和本地路径，选择后在详情内管理连接、检测与缓存；窄窗口上下排列。连接中可以取消，未完成移除只能继续原模式；操作按挂载独立忙碌。任务字节进度以十进制字节／kB／MB／GB／TB／PB／EB 自动换算，悬停显示精确字节，目录仍显示条目计数。挂载页支持连接、断开、刷新、打开目录和扫描本地改动。连接期间持续上传本地新增和修改，自动上传开关已移除；升级前的旧改动也自动纳入。取消、冲突、结果不明和远端删除保护继续生效。任务页按执行中、排队／等待、历史展示，同组保留提交顺序，字节进度更新不改变顺序；当前任务不受历史条数限制。独立任务页区分文件、目录及副本的远端目标，保留已完成上传的历史，显示字节进度、等待、冲突和结果待核对，支持取消、重试、另存远端副本及逐项结果；切换页面后任务继续。“清除已完成”只清除成功任务的展示历史，保留其他状态、上传基线和恢复数据，重启后生效。
4. WebDAV 默认开启“远端自动检测”：支持 RFC 6578 的集合每 60 秒增量检测，否则每 5 分钟完整对账；可为每个挂载关闭或调整两个间隔。挂载页显示实际模式、最近成功和错误。S3 默认开启每 5 分钟完整对账，可独立关闭或调整间隔；AWS S3 可额外配置默认关闭的 SQS 事件加速，R2 使用定时完整对账。“刷新”立即执行完整对账。确认删除后会清理本地未修改的已同步占位及缓存，**包括已固定文件**；本地修改、新建、占用及上传结果不明的内容保留并报告。已删除的路径和父目录不会因本地补扫或重启自动重新上传。
5. “移除挂载”提供“下载并移除”“清空并移除”和“取消”。已注册根的下载并移除保留全部剩余本地文件；从未注册成功的条目显示“移除挂载（保留本地文件）”，离线保留本地内容并移除配置。清空并移除永久删除根目录内全部内容，包括本地修改及新建文件，保留空根目录，不下载或删除文件源内容；提交前再次确认，默认取消。

6. “导出配置”可以选择 WebDAV／S3 挂载，用至少 8 个字符的备份密码生成 `.hmconfig` 加密文件，包含连接参数、凭据、随启动连接、缩略图和远端检测选项。新备份为 v3，兼容导入 v1／v2；SQS 选项及独立加密凭据可随备份迁移，游标、消息、事件与暂存快照不进备份。密码中的空白也参与加密。“导入配置”先解密并预览，可逐项重选本地 NTFS 空目录；只新增、重复项跳过，现有挂载不会被覆盖。导入后仅保存、不立即连接，可手动连接，之后启动按恢复的自动连接设置执行。文件可用于跨机器及打包／非打包模式迁移；SDK 默认凭据链只备份模式，需在目标机器另行配置。

挂载详情显示服务器报告的远端配额及成功时间。WebDAV 查询 RFC 4331 的可用／已用字节；两项同范围有效时计算总量，不代表 NAS 物理磁盘。缺失、无限或无效值为未知；S3 无通用容量接口，显示“未知（服务未提供）”。选择挂载复用五分钟缓存，重连和手动刷新更新，失败保留上次值。

移除失败或取消后会保留模式与状态，重启不会自动重放删除操作；再次选择相同方式重试。已经删除的内容不会因取消而恢复。

常规缓存操作会保护本地修改、新建、删除和重命名；明确选择清空时按上述范围删除。本版本自动上传新增文件、目录和文件修改；最后一次变化后默认等待 2 秒，连接恢复、监控溢出及每 60 秒补扫。**本地删除不删除远端；重命名上传新路径，保留远端旧项。** WebDAV 的干净已固定文件自动下载新版并保持固定状态；占用、修改或未决上传保持保护，取消当前版本后需显式重试或等待下一版本。手动“刷新”立即完整对账。WebDAV 全部协议操作使用 WebDAVClient 3.3.0 的 DavClient，每目录独立 RFC 6578 令牌，服务不支持时回退 Depth 1；S3 使用 AWS SDK v4、SigV4 签名及分页，路径寻址默认开启。默认 HTTPS，原子替换等未验证的能力保持未知。WebDAV 的可选空／非标准 ETag 不阻断枚举；缺少可靠标签时使用整文件快照缓存，可靠强标签仍严格验证版本。系统状态为本地（实心绿勾）、仅远端（云）及待脱水（空心绿勾，允许回收）。设置页可调整默认 10 GiB 的缓存软上限，0 关闭自动回收；固定、修改和活动内容不会为了达标而被回收。

上传使用挂载目录外的不可变快照，每根同时上传一个文件、全局最多两个；发送阶段持久化，结果不明时先只读核对远端；目标不存在且无法区分未写入与写入后被删除时，保留冲突，由用户显式重试或另存副本。取消本代后不会立即自动重传，可手动重试或再次修改。上传期间或提交后继续编辑会保留下一代；只有本地身份与内容仍匹配快照时才更新同步状态。同一路径在文件和目录之间变化时保持类型冲突，可恢复原类型后重试，或改名上传。断开、退出及移除会先停止调度并结束在途处理。

WebDAV 不创建辅助目录，必要的探测及安全上传临时文件保存精确 SQLite 日志；完成后清理，失败时在协议日志提示，重连核对重试，外部修改受到保护。WebDAV 与 S3 分别验证创建、更新及其他写能力，“测试连接”仍只读。无可靠条件或已知基线时拒绝覆盖，保留本地修改和远端内容。当前坚果云实测可通过临时上传及 `MOVE Overwrite:F` 安全新增，但其独占锁约束未通过验证，**现有文件更新会提示冲突，请在任务页“另存副本”**；仅声明支持 LOCK 不足以允许覆盖。S3 保留 SigV4、条件 PUT、条件分片完成及回执核对，ETag 不作为 MD5。完整对账先收齐全部分页，再 HEAD 确认变化和缺失；失败／取消／403 不当作删除。列表与 HEAD 之间变化会立即从第一页重扫，连续三轮不稳定时连接保留、5 秒后继续。列表毫秒时间按 HEAD 的整秒精度核对，索引保留精确列表时间。

AWS S3 的“SQS 事件加速”使用同区域 Standard Queue。每台机器需要独立专用队列，同进程同队列共享一个接收器；事件先落库再确认，并重新查询 S3 当前状态，不按消息直接删除本地。定时完整对账仍保留，队列故障不影响它。测试连接只读取队列属性，不 Receive／Delete、不创建队列或修改桶通知；消费权限在运行时验证。配置步骤、权限及 DLQ 见 [SQS 配置说明](docs/S3-SQS.md)。

读取会合并同时发生的整文件快照和元数据查询，取消一个请求不影响其他等待者，明确提交的下载优先并保留普通读取机会。首次打开大文件仍受服务速度及完整快照要求影响。每个挂载有默认关闭的“缩略图（实验性）”开关，支持 JPEG／PNG／BMP／GIF 首帧、MP4/H.264 视频帧和 EXE 内嵌图标。优先缓存和完整本地内容；远端只进行严格版本及范围校验的有界预览（8 MiB／32 次／10 秒），不水合原占位，也不退化到整文件缓存。不满足能力或预算时显示普通图标；坚果云当前需先显式下载完整内容。关闭会停止本挂载预览，已有缓存保留。正式 MSIX 暂不自动注册处理器；使用 -ExperimentalThumbnails 生成的实验包可注册，实际 Explorer 各显示路径仍待验收。

WebDAV 连接、远端检测和读取失败时显示安全的阶段、TLS／证书／超时／网络分类及错误码。普通只读请求对明确的瞬态故障最多尝试三次；证书验证失败不重试，需修正后断开再连接。严格缩略图请求保持原预算，写入失败仍可能需要核对结果。若调试器设置为“引发时中断”，继续运行后仍可能正常完成取消与退出，首次异常不等于程序崩溃。

关闭窗口默认隐藏到托盘。`--tray` 或 `--background` 可以静默启动，主窗口按需创建；普通重复启动恢复已有窗口。真正退出先停止接纳和取消全部在途工作，等待启动恢复及手动连接完成，再断开 CFAPI；重复退出共用一次收尾。同步根注册保留，未下载文件需再次启动应用才能读取。默认随程序启动连接挂载，Windows 登录启动仍默认关闭。

配置位于 `HKCU\Software\HybridMount.NET`，挂载定义在其 Mounts/Packaged 或 Mounts/Unpackaged 子键。运行索引和任务使用 SQLite，凭据按当前 Windows 用户 DPAPI 加密保存在 Mounting/Credentials，独立 SQS 凭据保存在 Mounting/Sqs/Credentials，整文件退化缓存位于 Mounting/RangeCache，图标缓存在 Mounting/PreviewCache，上传快照位于 Mounting/UploadStaging，固定远端更新快照位于 Mounting/RemoteStaging，这些缓存均计入软上限；待上传、冲突或结果不明的内容及其快照受到保护，可能暂时超过软上限。旧模拟源保留在 Mounting/MockSources，仅供旧挂载迁出；不自动改绑 WebDAV。打包数据位于本包 LocalState，非打包数据位于 `%LOCALAPPDATA%\HybridMount.NET`；调试使用独立挂载目录，不接管另一模式缺少配置的根。

日志页提供筛选、复制、导出与清除，最近显示 100 条，保留最多 30 天／10,000 条。主题、窗口背景和关闭行为可以在设置中调整。

生命周期诊断位于数据目录的 `Logs/lifecycle-*.jsonl` 和 `Logs/last-session.json`，保留最近 32 个会话；记录实际包身份、调试器状态、启动／退出阶段、取消原因及异常的类型、HRESULT 和安全堆栈，不保存异常原始消息或服务响应。正常退出记录 ExitCompleted；清理失败继续释放其他资源，并记录 ExitCompletedWithErrors。关联令牌已取消的读取按正常停止，HTTP 超时仍报告故障；已发送写入被取消保留结果待核对。缺少退出完成记录仅表示原因待定位，不能单凭 Visual Studio 的 `0xffffffff` 输出认定崩溃。通知合并和普通存在性查询不再通过重复抛出自有异常完成；SDK 自身已捕获的首次异常仍可能出现在调试输出中。

## 构建

安装 .NET SDK 10.0.401、Visual Studio 2026 的 C++ 桌面／ARM64 工具链、Windows SDK 10.0.26100.0 和 MSIX 工具。打开根目录的 **HybridMount.slnx**；解决方案仅包含以下三个工程：

| 工程 | 职责 |
| --- | --- |
| HybridMount | 界面、配置、生命周期和 NamedPipe 服务；输出 HybridMount.NET.exe |
| HybridMount.Ext | 原生资源管理器菜单与候选云缩略图处理器 |
| HybridMount.Tests | 生产服务契约及真实原生 DLL 集成测试 |

Visual Studio 调试选择：

| 运行方式 | 解决方案配置 | 启动配置 |
| --- | --- | --- |
| 打包调试 | Debug | HybridMount (Packaged) |
| 直接 EXE 调试 | DebugUnpackaged | HybridMount (Unpackaged) |

Release／ReleaseUnpackaged 同理。非打包配置设置 `WindowsPackageType=None`，可直接运行 EXE；扩展、测试工程在 Unpackaged 配置中复用对应 Debug／Release 构建。输出按架构、配置、Packaged／Unpackaged 隔离。

使用 Visual Studio“创建应用程序包”时，选择主程序的 Release 配置及 x64 或 ARM64；解决方案为打包 Debug／Release 显式启用部署，非打包配置不参与部署。更新工程文件后重新加载 **HybridMount.slnx** 再打开向导。产品版本集中在 Directory.Build.props，当前为 `0.0.8`；供向导读取的 Package.appxmanifest 必须同步为四段 `0.0.8.0`，构建会拒绝版本不一致，自动增加修订号保持关闭。

在根目录使用 PowerShell 7：

```powershell
# 依次构建扩展和主程序，再执行 x64 测试
.\build\Build.ps1 -Platform x64 -Configuration Debug -Deployment Unpackaged -Test

# 自包含 MSIX；-Package 默认选择 Packaged；不提供证书参数时输出未签名包
.\build\Build.ps1 -Platform x64 -Configuration Release -Package
.\build\Build.ps1 -Platform ARM64 -Configuration Release -Package

# 使用当前用户证书存储中的匹配 Publisher 证书签名并验证
.\build\Build.ps1 -Platform x64 -Configuration Release -Package -CertificateThumbprint '<证书指纹>'

# 显式生成注册缩略图处理器的实验包；每挂载仍默认关闭
.\build\Build.ps1 -Platform x64 -Configuration Release -Package -ExperimentalThumbnails -CertificateThumbprint '<证书指纹>'

# 从本项目矢量母版重新导出 PNG / ICO
.\build\Update-Assets.ps1
```

正式产物位于 `artifacts\packages\<架构>`，实验缩略图包位于 `artifacts\packages-preview\<架构>`，构建日志、TRX 与包哈希位于 `artifacts\validation`。ARM64 可以交叉构建，测试运行必须在 ARM64 主机进行。直接构建主工程前，需要先构建同架构、同配置的扩展；推荐使用上述脚本或 slnx。

已签名且证书受本机信任时，可通过 `Add-AppxPackage -Path '<包路径>'` 安装。MSIX 同时注册菜单和 StartupTask；不需要手工使用 regsvr32。未打包开发运行不注册 Explorer 菜单，登录启动使用当前用户 Run 项。

验证细节及待测项目见 [docs/Validation-0.0.8.md](docs/Validation-0.0.8.md)，迁移来源见 [docs/Migration-0.0.1.md](docs/Migration-0.0.1.md)。路线图保存在根目录 HybridMount-devplan.md。AWS SDK 的 S3 与 SQS 组件采用 Apache-2.0，随包附带 ThirdParty/AWSSDK/License.txt 和 Notice.txt；WebDAVClient 3.3.0 采用 MIT，随包附带实际 NuGet 包的 ThirdParty/WebDAVClient/LICENSE.txt 和 NOTICE.txt。


本版真实自动同步验收可使用 `build/Test-RemoteSync.ps1 -OriginalRoot D:\wdavtest`：只读原配置和 DPAPI 凭据，在既有远端目录内使用唯一文件及独立本地根，完成后精确清理，不批量上传原改动、不创建远端测试目录。

历史 WebDAV 长时验证为显式操作，不随普通测试自动联网。`build/Test-WebDav.ps1` 使用独立工作目录和当前用户 DPAPI 凭据，默认运行 65 分钟；配置与实际服务边界见 [LAN 测试记录](docs/Validation-0.0.5.3-WebDAV-LAN.md)。
